# istSOS4Things Smart Monitoring Assignment Package

This package contains:

- `sensor_data_quality_checks.md`: general introduction to sensor data quality checks.
- `case_1_river_level_drift.ipynb`: river level monitoring and sensor drift.
- `case_2_slope_missing_data.ipynb`: slope displacement monitoring and missing data.
- `case_3_bridge_faulty_sensor.ipynb`: bridge vibration monitoring and faulty spikes/outliers.
- `case_4_extreme_rainfall_event.ipynb`: rainfall monitoring and extreme event detection.
- Four CSV datasets used by the notebooks.
- `datasets_summary.csv`: compact overview of the four cases.

Suggested workflow:

1. Run the istSOS4Things workshop.
2. Assign one case per group.
3. Ask students to ingest the dataset into istSOS4Things.
4. Ask students to complete the notebook.
5. Ask students to create a dashboard and alerting logic.
6. Ask students to present a short technical demo.
